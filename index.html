Molarium

Methods

Molarium is a local-first molecular workspace. Its molecular viewer is a custom HTML Canvas renderer implemented in this repository.

Structure
RDKit WebAssembly · RCSB PDB and CCD
Simulation
Sage/Rosemary WebGPU · STORMM-style WebGPU ensembles
ML potentials
ANI-2x through ONNX Runtime Web
Folding
OpenFold 2 ONNX · configurable ColabFold-compatible MSA service

Coordinates and calculations remain in the browser except for explicit PDB/CCD retrieval and MSA searches.

Reference checks compare browser calculations with the same numeric systems evaluated by OpenMM and with pinned native model outputs.

  • OpenFF Sage energy and force parity against an internal OpenMM Reference oracle
  • SHAKE/RATTLE constraint residual and deterministic replay checks
  • RDKit, ANI-2x and OpenFold pinned-version regression fixtures
  • Browser behavior, preparation and trajectory regression suite

Experimental methods stay labelled in the interface; a passing implementation comparison is not a claim of scientific validation for every system.

Interface design inspired by Atomiverse. Molarium’s interface and Canvas viewer were independently implemented; Atomiverse and its referenced xyzrender project are not bundled dependencies.
