# Molarium perspective: Prism-friendly LaTeX project

Use `main.tex` as the root document.

The project deliberately uses a conventional stack:

- `article` class
- pdfLaTeX
- `natbib` plus BibTeX
- vector PDF figures under `figures/`
- relative paths only
- no custom fonts, shell escape, or generated-at-compile-time graphics

## Local build

```sh
latexmk -pdf -interaction=nonstopmode main.tex
```

The compiled manuscript is `main.pdf`.

## Prism import

Import the project directory or the supplied zip and choose `main.tex` as the root file. `references.bib` and every used figure are included beside it.

## Draft status

The numerical Molarium claims are intentionally labelled provisional. A submission-ready version should tie them to a frozen repository state, a machine-readable validation ledger, and the redacted development-provenance archive described in the manuscript.
