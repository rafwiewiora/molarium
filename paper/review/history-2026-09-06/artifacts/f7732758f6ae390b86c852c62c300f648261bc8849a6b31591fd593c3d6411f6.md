# Molarium LaTeX package

Prism-friendly source package for:

**Molarium: When Molecular Design Software Becomes Generated Infrastructure**

## Entry point

`main.tex`

## Included files

- `main.tex` — manuscript source
- `references.bib` — BibTeX bibliography
- `figures/fig1_molarium_views.png` — Molarium View / Build / Inspect composite
- `figures/fig2_architecture.png` — local-first architecture figure
- `figures/fig3_build_loop.png` — scientist-agent build loop
- `figures/fig4_evidence_ladder.png` — evidence ladder
- `figures/fig5_value_layers.png` — three-layer value model

## Local compilation

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The source intentionally uses the standard `article` class and common LaTeX packages to make ingestion and recompilation straightforward.
