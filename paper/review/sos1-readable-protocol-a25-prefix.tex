\subsubsection{Pseudocode for the complete movie}

Listing~\ref{lst:sos1api} is a reading guide to the full executable API record, not a separately executable script. Lettered blocks link the procedure to Fig.~\ref{fig:sos1story}; checkpoint numbers link it to the seven saved movie states. Panel D shows checkpoint 5, after the graph-only checkpoint 4. Chemical selectors and arguments are abbreviated, repeated trials become loops, and repeated inspections, workspace changes, and session-resumption calls are omitted. A \texttt{\#} marks a comment; unprefixed lines specify operations or checks. These include both API operations and checks performed by the surrounding audit, not only assertions enforced by the script runner.
